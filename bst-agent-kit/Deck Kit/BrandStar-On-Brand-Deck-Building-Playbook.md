# BrandStar: Build On-Brand Decks With an Agent

Version 2.0 · November 12, 2026

## Start here

Use this playbook with your agent to turn a brief into a BrandStar presentation using the approved BST Slides Kit. The team supplies the goal, facts, assets and feedback. The agent organizes the story, selects approved layouts, drafts copy, assembles the deck when it has the right Figma access, and checks every slide.

**Live kit:** [BST Slides Kit](https://www.figma.com/design/WigwY2Fck85i84nXz55r6p/BST-Slides-Kit?node-id=106-374)

Give the agent this Markdown file and the live kit link. It must read the kit before building. The kit is a Figma Design file containing slide layouts, components and rules. Use a separate authorized working file for your deck and preserve the master kit. Jackson Sauder is the lead designer and final design authority.

This workflow requires no particular drive, computer or folder structure.

## 1. Understand how the kit works

| Part | What it does | How to use it |
| --- | --- | --- |
| Cover page | Entry point | Start here, then open the instructions. |
| Kit Instructions | Explains deck recipes, layout limits, copy budgets and review | Read before outlining. |
| Design System | Holds reusable layouts, typography, colors, components, imagery and division variants | Build from these existing assets. |
| Components | Reusable slide elements such as eyebrow and footer | Keep instances attached and edit through supported properties. |
| Text styles | Eight approved levels of typography | Apply existing styles rather than inventing sizes or weights. |
| Color modes | Division-specific presentation treatments | Select the mode for the offer being sold. |

If the agent cannot inspect the live file, it should say so and prepare a content outline from the supplied information. It must not claim that an invented layout matches the kit. If it can read but cannot edit Figma, it can produce a slide-by-slide assembly brief for a teammate.

## 2. Give the agent a complete brief

Supply these details, or mark missing items TBD:

- **Client and project:** who the deck is for and what it is called.
- **Audience:** who will read it and what they already know.
- **Goal:** the decision or next action the deck should produce.
- **Offer:** what the client is buying from BrandStar.
- **Deck type:** pitch, proposal/plan, sales/onboarding, results recap or show sell sheet.
- **Facts:** approved scope, pricing, dates, metrics and source references.
- **Assets:** approved logos, photography, examples and image-usage permissions.
- **Constraints:** presentation length, required slides and sensitive information.
- **Review:** content reviewer, Jackson’s design/sign-off review and any client or legal approvals.
- **Output:** editable Figma deck and any requested PDF or other deliverable.

The agent should summarize the brief and ask only for missing information that materially changes the deck. It can continue outlining independent sections while specific facts remain unresolved. Never invent results, prices, names, quotes or contact details.

## 3. Choose the right BrandStar treatment

Route by **what the client is buying**, rather than the subject of the presentation.

| Division | What the deck sells | Brand treatment |
| --- | --- | --- |
| Studios | Production, shoots, virtual production, podcasting, events and related creative services | Blue; approved dark and Studios Light layouts. |
| Entertainment | Integration in BrandStar shows, branded segments and show sponsorship | Yellow; white base with strong photography. |
| Marketing | Strategy, branding, media buying, advertising, PR, social, websites, SEO or CRM | Green; white base. |
| Umbrella | Multiple divisions or an introduction to BrandStar as a company | Neutral cover/chrome/close; division modes within chapters. |

Examples: making a TV spot is Studios; buying airtime is Marketing; putting a brand inside a BrandStar show is Entertainment. A production-plus-media-buy proposal uses Umbrella chapters.

Use one division accent per slide. Client branding appears through approved client logos and creative, without replacing the BrandStar color system. Use the supplied color tokens rather than manually entering colors.

For Studios, the live rules identify Feature, Stats, Columns and Highlights as **Studios Light** slides. Cover, Divider, Image Wall, Contact and Back Cover remain dark. Image Wall is black across divisions. See the unresolved dark/white ratio note below.

## 4. Outline the story before designing

Build a clear arc: **open → establish the need and offer → show how it works → prove the claim → ask for the next step**.

For each slide, propose its number, takeaway headline, approved layout, essential copy, image or evidence, and any missing input. Headlines should state the point the audience should remember.

**Default proposal recipe:** Cover → Statement → Split → Plan → Process → Timeline → Columns → Contact → Back Cover.

Other recipes in the kit:

- **Pitch/capabilities:** Cover → Statement → Divider → Split → Pillars → Feature → Divider → Process → Columns → Quote → Contact → Back Cover.
- **Sales/onboarding:** Cover → Numbered List → Info Grid → Funnel → Steps → Timeline → Contact → Back Cover.
- **Results recap:** Cover → Statement → Stats → Band → Highlights → Progress → Quote → Contact → Back Cover.
- **Show sell sheet:** Cover → Full Bleed → Band → Feature → Stats → Quote → Back Cover.

Use a recipe that fits the purpose and available evidence. Do not add fabricated proof to fill a recipe. Most decks are 8–16 slides; beyond 20, consider a separate leave-behind. Avoid repeating the same layout on adjacent slides. Use no more than one Statement and one Full Bleed per eight slides.

**Outline review:** the kit calls for Jackson’s approval of the outline before building. Present the proposed story, missing inputs and consequential questions together for review.

## 5. Select from the approved layouts

Choose by communication goal, then follow the layout’s specific limits. If content does not fit, cut or split it rather than designing a new layout.

| Family | Layout | Use and key limits |
| --- | --- | --- |
| Openers | Cover | First slide; short title, client subtitle and required right-side image. |
| Openers | Statement | One central problem or belief; short title and two-sentence body. |
| Openers | Divider | Chapter opener; fixed shade stack, no photo. |
| Image-led | Split | One idea supported by a portrait/square image. |
| Image-led | Full Bleed | Hero image with brief bottom-left text. |
| Image-led | Band | Story beat with a wide image suitable for a 1920 × 400 crop. |
| Image-led | Image Wall | Fourteen distinct images; black background, brief white title, no chrome. |
| Overviews | Numbered List | Three to six principles or agenda items; not a sequence. |
| Overviews | Info Grid | Exactly six reference cards in a 2 × 3 grid. |
| Overviews | Feature | Exactly three offerings, each with an image. |
| Overviews | Plan | Three-part plan; highlight at most one part. |
| Overviews | Pillars | Exactly two pillars and one image. |
| Process | Funnel | Three columns: awareness, consideration and conversion; up to eight bullets each. |
| Process | Process | Internal workflow with three to five steps; four is the default. |
| Process | Steps | Two to four actions the audience must take; at most three callout rules. |
| Process | Timeline | Exactly five stages with dates and owners. |
| Process | Progress | Status update with two to three points; not a first pitch. |
| Proof | Stats | Exactly four sourced numbers; four characters maximum per number. |
| Proof | Columns | Exactly three statistics, each with one line of context. |
| Proof | Highlights | Exactly six metric cards; not in the first half of a pitch. |
| Proof | Quote | Two press items plus one verbatim quote, up to approximately 60 words. |
| Proof | Logo Wall | Up to sixteen one-color logos per group, two groups maximum; one wall per deck. |
| Close | Contact | One to four real team cards; ordinarily second-to-last. |
| Close | Back Cover | Last slide; short sign-off and website URL. |

The show sell-sheet recipe omits Contact. Follow the chosen recipe and flag conflicts with general sequencing rules instead of adding unsupported content.

## 6. Build within the brand system

1. Use approved layout frames in the authorized working file. Preserve attached instances, layout structure and component relationships.
2. Fill text through the provided properties where available. Preserve the eyebrow, footer and page numbering; follow special-layout exceptions such as Image Wall.
3. Use the eight existing text styles: **Display, Title, Subtitle, Heading, Body, Caption, Label and Number**. Check font availability and the approved Typography mode. Do not silently substitute fonts or change master styles.
4. Apply the appropriate division and slide modes. Do not recolor individual elements to imitate another division.
5. Replace image placeholders with approved images using Fill crops. Keep people and products proportional; never stretch an image.
6. Preserve the established spacing and content area. The live rules place ordinary content above **y = 920**, with the footer at **y = 985**. Full-bleed imagery and other named layout exceptions follow their own rules.
7. If something is missing from the system, show Jackson the content and why the existing layouts do not fit. Do not alter the master or invent a replacement.

Do not rebuild the kit through a converter or generate a visually similar deck from scratch. An agent’s job is to assemble the approved system and adapt the content to it.

## 7. Keep the copy readable

Use the tighter limit whenever a layout-specific limit and a general budget differ.

- One main idea per slide; short, active sentences and no hype.
- General headline ceiling: eight words/two lines; some layouts are tighter.
- Intro: one to two sentences, approximately 25 words.
- Content slides: aim near 50 words; never exceed the kit’s 75-word ceiling.
- Body block: approximately 50 words maximum; card copy: approximately 20 words.
- Bullets: three to five, approximately eight words each, subject to the layout’s own limits.
- Minimal slides—Cover, Statement, Divider, Full Bleed, Image Wall and Back Cover—have a general 15-word budget.
- Use numerals with units. Label and source every figure; preserve quotation wording and attribution.

When copy overflows: **cut words → split the idea → choose another approved layout → move reference detail to a leave-behind**. Never shrink typography or stretch containers to hide overflow.

## 8. Review every slide

The agent must inspect an actual screenshot or rendered preview of every slide. A structural check or successful export alone is insufficient.

- [ ] The headline communicates a clear takeaway and the slide can be scanned quickly.
- [ ] The approved layout and its content counts fit the idea.
- [ ] Fonts, colors, modes and components follow the kit.
- [ ] Text fits; no clipping, collisions, awkward wrapping or content below the allowed area.
- [ ] Images have suitable crops, correct proportions and known usage permission.
- [ ] Eyebrows, footers and page numbers are consistent where applicable.
- [ ] No placeholder names, missing images or unsupported claims remain in a release candidate.
- [ ] Figures have sources; quotes are verbatim; contact details are real.
- [ ] The deck has a coherent arc, varied layouts and a clear next step.

Report checks as passed, failed or not checked. Fix failed slides and inspect them again. Put unresolved facts and conflicts in the review note; never describe an unverified deck as approved.

## 9. Handoff and approval

Give the reviewer the editable working-file link, requested review export, a short description of the deck’s purpose, and a concise list of missing facts or decisions. Preserve the relationship between the reviewed export and its editable source.

Jackson’s sign-off is the kit’s release gate. A teammate or agent finishing the build does not authorize sending, publishing or scheduling it. Keep client/legal review requirements visible when applicable.

## 10. Known source conflicts

These questions were visible in the inspected kit. They do not require every teammate to resolve them independently. Use existing approved styles/layouts, flag the affected choice and obtain Jackson’s decision when necessary.

- **Studios dark/white ratio:** one live section specifies 80–85% dark and 15–20% white; another paragraph says 60/40. Do not present either ratio as settled. Preserve the named Studios Light layout assignments while the ratio is clarified.
- **Layout count:** the instruction book flags 24 versus 21 and explicitly gives Spec Sheet v1.1’s 24 precedence pending confirmation. This guide lists those 24.
- **Typography weights:** Body, Caption and Number weights differ between written guidance and styles. Preserve the existing approved styles; do not fix the master by guessing.
- **Mode selection:** general instructions say to set the division mode once; specific Studios rules require Studios Light on named slides. Apply the specific slide treatment within the Studios division.

# Between Takes

Playbooks for producing and reviewing Between Takes podcast episodes. Notion is where these pages are written. These files are the copy in this repo, last synced 2026-11-12.

Episode tasks stay on the [Between Takes project](https://app.notion.com/p/4166d55232fa812992e7e7551607aec5) in Notion. The same ten playbooks are also inside [bst-agent-kit/Playbooks/Between Takes/](../bst-agent-kit/Playbooks/Between%20Takes/) so agents can follow them from the kit.

## Playbooks

- [Between Takes Editing Rules](Between%20Takes%20Editing%20Rules.md) — queue intake, separate Premiere revisions, episode build order, timeline organization, export QC, and storage rules.
- [Between Takes Frame.io Process](Between%20Takes%20Frame.io%20Process.md) — assembly line from filming to distribution, metadata routing, version stacks, review comments, and DIT folders.
- [Between Takes Sound Engineering Rules](Between%20Takes%20Sound%20Engineering%20Rules.md) — mic diagnosis, sync, dialogue processing, routing, loudness, and final MP4 sign-off.
- [Between Takes Intro and Outro](Between%20Takes%20Intro%20and%20Outro.md) — Version 04 assets, the red-dot intro cut, and opening and closing checks.
- [Between Takes Highlights — Before the Intro](Between%20Takes%20Highlights%20%E2%80%94%20Before%20the%20Intro.md) — the opening hook: excerpts, J/L cuts, fixed crops, and the hard cut into the intro.
- [Between Takes Multi Cut Style](Between%20Takes%20Multi%20Cut%20Style.md) — host close-up to room wide, active-speaker coverage, and synchronized joins.
- [Between Takes Animation Style](Between%20Takes%20Animation%20Style.md) — lower thirds, Gotham type, gradient, and title timing.
- [Between Takes Review Process](Between%20Takes%20Review%20Process.md) — reviewing the highlights opening and recording feedback against that version.
- [Between Takes Routines](Between%20Takes%20Routines.md) — the five-step routine for building and handing off the highlights hook.
- [Between Takes Notion Updates](Between%20Takes%20Notion%20Updates.md) — keeping the shared highlights guidance and episode records consistent.
